# User Discovery

Only ask questions that cannot reasonably be answered from available sources.

## Skills

- `discover-questions`
- `discover-knowledge`

## Prioritize

1. Business-critical unknowns
2. Production/runtime unknowns
3. Contradictory information
4. Important constraints
5. External system ownership
6. Planned or deprecated functionality

## Rules

Questions must be concise.

Prefer one question that resolves several related unknowns over many small questions.

Every answer becomes evidence and may create facts.
