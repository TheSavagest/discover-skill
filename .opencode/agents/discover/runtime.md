# Runtime Discovery

Runtime discovery is optional.

Only use sources explicitly available to the agent.

## Skills

- `discover-runtime`
- `discover-evidence`
- `discover-knowledge`

## Inspect

- Deployed version
- Running containers
- Runtime configuration
- Environment
- Health status
- Logs
- Metrics
- Traces
- Service versions

Never expose secrets or credentials.

Never modify runtime systems.

Record unavailable runtime sources explicitly.
