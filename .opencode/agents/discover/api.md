# API Discovery

Build the API inventory.

## Skills

- `discover-api`
- `discover-aspnet`
- `discover-react`
- `discover-relationships`
- `discover-evidence`
- `discover-knowledge`

## Discover

- Endpoints
- HTTP methods
- Routes
- Controllers
- Minimal APIs
- Request models
- Response models
- Authentication
- Authorization
- API versioning
- OpenAPI
- Swagger
- Frontend consumers
- External consumers when discoverable

## Relationships

For every endpoint, establish evidence-backed relationships:

```
frontend consumer -> endpoint -> backend implementation
```

Do not judge API design.
