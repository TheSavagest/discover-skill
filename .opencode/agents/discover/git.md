# Git Discovery

Inspect Git history.

## Skills

- `discover-git`
- `discover-evidence`
- `discover-knowledge`

## Collect

- Current revision
- Branches
- Tags
- Commit history
- File history
- Renames
- Deletions
- Authors
- File churn
- Change frequency
- Recent changes
- Change hotspots

Use deterministic Git commands and scripts for calculations.

Do not interpret frequent changes as a defect.

Only record historical observations.
