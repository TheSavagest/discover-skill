# Integration Discovery

Discover external dependencies.

## Skills

- `discover-integrations`
- `discover-api`
- `discover-infrastructure`
- `discover-relationships`
- `discover-evidence`
- `discover-knowledge`

## Inspect

- HTTP clients
- SDKs
- Third-party APIs
- Payment providers
- Identity providers
- Email/SMS
- Storage
- Queues
- Message brokers
- Webhooks
- Event publishers
- Event consumers
- External databases
- Service-to-service communication

## Output

For each integration record:
- Name
- Type
- Purpose if directly observable
- Configuration source
- Consuming entities
- Evidence

Do not infer business criticality without evidence.
