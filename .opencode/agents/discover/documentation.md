# Documentation Discovery

Find and catalog documentation.

## Skills

- `discover-documentation`
- `discover-file-analysis`
- `discover-evidence`
- `discover-conflicts`
- `discover-knowledge`

## Inspect

- README files
- docs directories
- Markdown
- ADRs
- Architecture documents
- API documentation
- Runbooks
- Deployment documentation
- Contributing guides
- Comments containing architectural or business statements

Extract explicit statements as evidence-backed facts.

Do not assume documentation is correct.

If documentation contradicts code or runtime information, create a conflict.
